# Data dictionary

Generated by `pipeline/build.py` from `pipeline/schema.py`. Every table is written to `data/csv/<name>.csv` and `data/json/<name>.json` (an array of row objects). `data/json/meta.json` holds as-of dates, definitions and sources.

## team_summary

One row per FBS team (138) with identity, rankings, every record split and game control. Start here.

138 rows.

| Column | Meaning |
|---|---|
| `team_id` | ESPN team id. Join key for every table. |
| `team` | Short team name as ESPN lists it (for example Ole Miss, Miami, Miami (OH)). |
| `display_name` | Full name with mascot. |
| `abbreviation` | ESPN abbreviation. |
| `conference` | 2026 conference: ACC, Big 12, Big Ten, SEC, Pac-12, Ind, American, C-USA, MAC, Mountain West, Sun Belt. |
| `group` | Power 4, Notre Dame, Pac-12 or Other FBS. |
| `in_power_set` | True for the 76 teams of the original request: ACC, Big 12, Big Ten, SEC, Notre Dame and the 2026 Pac-12. |
| `color` | Primary color, hex without the #. |
| `alt_color` | Secondary color, hex without the #. |
| `logo` | ESPN-hosted logo URL (light backgrounds). School marks are trademarks; check usage rights before publishing. |
| `logo_dark` | ESPN-hosted logo URL for dark backgrounds. |
| `wins` | Wins in completed regular-season games. |
| `losses` | Losses in completed regular-season games. |
| `win_pct` | wins / (wins + losses). |
| `ap_rank` | Rank in the latest AP Top 25, empty if unranked. |
| `ap_points` | Voting points in the latest AP poll, for ranked teams and others receiving votes. |
| `ap_status` | Top 25, Receiving votes, or empty. |
| `ap_polls_ranked` | Number of 2026 AP polls (preseason included) in which the team was ranked. |
| `ap_best_rank` | Best AP rank this season, empty if never ranked. |
| `ever_ap_ranked` | True if the team appeared in any 2026 AP Top 25. |
| `cfp_rank` | Rank in the latest College Football Playoff committee Top 25, empty if unranked. |
| `talent_rank` | Rank (1-138) in the 247Sports 2026 Team Talent Composite, a preseason ranking of roster talent. |
| `talent_tier` | 1 = talent rank 1-25, 2 = 26-50, 3 = 51 or lower. |
| `model_rank` | Rank among all 138 FBS teams in the project's own model (see methodology). |
| `model_score` | Model score: 0.7 x Colley z-score + 0.3 x capped-margin SRS z-score. |
| `colley` | Colley rating (schedule-adjusted wins and losses). |
| `srs` | Simple rating system value in points (margin capped at 24, opponent-adjusted). |
| `top50_rank` | Rank on the top-50 list, empty if not on it. |
| `top50_basis` | Why the team sits where it does on the top 50: AP Top 25, AP receiving votes, or Projected. |
| `vs_ap_ranked_w` | Wins against opponents that appeared in at least one 2026 AP Top 25 (preseason through the latest poll), whenever the game was played. |
| `vs_ap_ranked_l` | Losses against opponents that appeared in at least one 2026 AP Top 25 (preseason through the latest poll), whenever the game was played. |
| `vs_ap_unranked_w` | Wins against opponents never in the 2026 AP Top 25, FCS opponents included. |
| `vs_ap_unranked_l` | Losses against opponents never in the 2026 AP Top 25, FCS opponents included. |
| `vs_cur_ranked_w` | Wins against opponents ranked in the latest poll (AP or CFP, whichever was released last; see meta.json latest_poll), whenever the game was played. |
| `vs_cur_ranked_l` | Losses against opponents ranked in the latest poll (AP or CFP, whichever was released last; see meta.json latest_poll), whenever the game was played. |
| `vs_talent_t1_w` | Wins against opponents ranked 1-25 in the 247Sports Team Talent Composite. |
| `vs_talent_t1_l` | Losses against opponents ranked 1-25 in the 247Sports Team Talent Composite. |
| `vs_talent_t2_w` | Wins against opponents ranked 26-50 in the 247Sports Team Talent Composite. |
| `vs_talent_t2_l` | Losses against opponents ranked 26-50 in the 247Sports Team Talent Composite. |
| `vs_talent_t3_w` | Wins against opponents ranked 51 or lower in the talent composite, plus FCS opponents (which have no talent rank). |
| `vs_talent_t3_l` | Losses against opponents ranked 51 or lower in the talent composite, plus FCS opponents (which have no talent rank). |
| `home_w` | Wins in home games. |
| `home_l` | Losses in home games. |
| `away_w` | Wins in road games. |
| `away_l` | Losses in road games. |
| `neutral_w` | Wins in neutral-site games. |
| `neutral_l` | Losses in neutral-site games. |
| `lead_pct` | Share of regulation game time the team was ahead (0-1). |
| `tied_pct` | Share of regulation game time the score was tied (0-1). |
| `trail_pct` | Share of regulation game time the team was behind (0-1). |
| `avg_lead` | Scoring margin averaged over every second of regulation, in points per game. |
| `ng_margin_pg` | Average margin per game counting only points scored outside garbage time (lead of 38+ in Q2, 28+ in Q3, 22+ in Q4). Overtime points count. |
| `margin_pg` | Average final scoring margin per game. |
| `games_never_trailed` | Wins in which the team was never behind. |
| `comeback_wins_10` | Wins after trailing by 10 or more points. |
| `blown_leads_10` | Losses after leading by 10 or more points. |
| `biggest_deficit_overcome` | Largest deficit in any win, empty if no wins. |
| `biggest_lead_lost` | Largest lead in any loss, empty if no losses. |
| `lead_pct_rank` | Rank among 138 FBS teams by lead_pct. |
| `avg_lead_rank` | Rank among 138 FBS teams by avg_lead. |
